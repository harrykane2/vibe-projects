## Запуск проекта с нуля

1. Установите Git.
2. Установите Node.js версии 22 или новее.
3. Клонируйте репозиторий:

```bash
git clone https://github.com/harrykane2/vibe-projects.git
cd vibe-projects
```

4. Установите зависимости:

```bash
npm install
```

5. Создайте файл `.env` из шаблона для Better Auth:

```bash
cp .env.example .env
```

Замените `BETTER_AUTH_SECRET` в `.env` на собственную случайную строку длиной не менее 32 символов. Настоящий секрет не добавляйте в Git.

Для входа через Better Auth создайте таблицы библиотеки и учебные учётные записи:

```bash
npm run auth:migrate
npm run auth:seed
npm start
```

## Учебные учётные записи

| Роль | Электронная почта | Пароль |
| --- | --- | --- |
| Родитель (`parent`) | `uchebny-roditel@example.com` | `Rodytel-2026!` |
| Сотрудник (`staff`) | `uchebny-sotrudnik@example.com` | `Sotrudnik-2026!` |

Пароли хранятся в учебной базе только в хешированном виде средствами Better Auth. Пароли приведены в документации для локального входа.

### Запуск лендинга

```bash
npm start
```

Откройте в браузере: http://127.0.0.1:3000

## Основной сценарий вручную

1. Откройте http://127.0.0.1:3000.
2. Проверьте заголовок «Сравним кружки за вас — по цене и дороге».
3. Нажмите «Оставить заявку» или прокрутите страницу до формы.
4. Введите возраст ребёнка от 4 до 12 лет.
5. Укажите район или школу.
6. Укажите удобное время.
7. Укажите способ связи.
8. Отправьте форму.
9. Проверьте сообщение: «Заявка отправлена. Мы получили ваши данные и свяжемся с вами.»

Для проверки ошибки отправьте пустую форму или возраст меньше 4 либо больше 12. На экране должно появиться понятное сообщение с описанием исправлений.

Заявки сохраняются в SQLite-файл `data/ryadom.sqlite`.
