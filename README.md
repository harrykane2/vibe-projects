# Рядом

Документация первой версии лендинга ручного подбора кружков и секций для занятых родителей.

## Что есть в репозитории

- [spec.md](spec.md) — описание продукта, аудитории, сценария и ограничений первой версии.
- [Plan.md](Plan.md) — план разработки лендинга и ручного подбора от нуля до запуска.
- [ryadom/](ryadom/) — исходные материалы первого проекта.

На этом этапе код приложения не написан: в репозитории нет HTML, CSS и JavaScript.

## Запуск проекта с нуля

1. Установите Git.
2. Клонируйте репозиторий:

```bash
git clone https://github.com/harrykane2/vibe-projects.git
cd vibe-projects
```

3. Откройте папку в редакторе или просмотрите документацию из корня репозитория:

```bash
open spec.md
open Plan.md
open README.md
```

Команды `open` подходят для macOS. На другой операционной системе откройте эти файлы через редактор или файловый менеджер.

### Запуск лендинга

Исполняемый лендинг пока не добавлен. Приложение нельзя запустить до реализации шагов из [Plan.md](Plan.md). После реализации лендинга в репозиторий должны быть добавлены конкретные инструкции по установке зависимостей и запуску локального сервера; этот раздел следует обновить без добавления новых функций.

## Основной сценарий вручную

Этот сценарий будет проверяться после реализации лендинга.

1. Откройте страницу лендинга.
2. Проверьте, что на первом экране сохранено обещание и надпись кнопки заявки в соответствии с [spec.md](spec.md).
3. Нажмите кнопку заявки.
4. Заполните поля заявки — точный набор обозначен как `{ПОЛЯ ЗАЯВКИ}`.
5. Отправьте заявку.
6. Проверьте, что родителю показан ответ — точно: `{ОТВЕТ РОДИТЕЛЮ}`.

Перед отправкой убедитесь, что форма не содержит функций или полей, которых нет в исходных материалах проекта. Результат ручной проверки считается корректным, если заявка отправляется и ответ родителю отображается дословно в соответствии с формулировками спецификации.
